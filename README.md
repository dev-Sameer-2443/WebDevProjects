# 📚 Satori Shelf

Satori Shelf is a clean and modern **online bookstore website** built using **HTML + CSS**.  
It focuses on a philosophical and minimal aesthetic where users can explore popular books and discover meaningful reads.

---

## ✨ Features

- 🏠 Beautiful Home Page (Hero Section + Popular Books)
- 📖 Popular Books Section with Book Covers
- 🎨 Smooth UI with hover effects
- 🔐 Login Page (Username + Password)
- 🌙 Dark theme + premium look

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- (Optional) JavaScript (for future upgrades)
